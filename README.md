# Homebrew tap for Sequence

This is the official Homebrew tap for the Sequence command-line interface, `sq`.

## Install

```bash
brew tap rockstarsunlimited/sequence
brew install sequence
```

The CLI supports Apple Silicon Macs running macOS 15 or later.

## Update

```bash
brew update
brew upgrade sequence
```

Run `sq doctor` after installation to check the CLI, Sequence app, and runtime compatibility.

Product documentation and support are available at [sequencetool.com](https://sequencetool.com).
